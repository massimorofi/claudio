Claudio Architecture Map

One recursive loop does the work. Everything else — persistence, compaction, recovery, subagents — is a harness that keeps that loop fed, honest, and restartable.

The workflow view

The loop's internal state made visible. Four surfaces turn each turn's events into something the user can read at a glance — and all four reconstruct from disk after a reload.
